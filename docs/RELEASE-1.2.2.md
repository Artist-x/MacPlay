# MacPlay1.2.2

本次更新完善无线网络交接，改进CarPlay窗口显示和音频会话管理。

## 更新内容

- 无线认证后重新广播接收服务，等待期间受控广播，帮助稍后加入Wi-Fi的iPhone发现MacPlay。
- 控制服务回应成功后保留15秒回连等待；尚未建立网络连接时有限重试，成功回应最多3次。手机建立控制连接后停止探测，避免重复请求干扰会话。
- 网络交接日志区分接口就绪、服务发现、地址解析、控制请求和手机回连，超时附带统计；发现进度不覆盖主窗口连接状态。
- 收到视频配置时先准备解码器，首帧成功解码后才显示CarPlay窗口。旧连接的延迟回调不会重新打开窗口。
- 新增“严格按屏幕物理像素显示”开关，默认关闭。初始窗口适配屏幕并限制在可用区域的80%以内，可等比例调整大小，不改变向iPhone请求的分辨率。开启严格像素显示后保持固定大小。原生像素模式始终全屏显示。
- 包含悬浮标题栏和后台窗口恢复改进：鼠标在画面顶部停留片刻显示标题栏，可拖动、最小化和关闭；关闭仍需确认断开。感谢Artist-x的PR#6。
- 保留1280×720默认分辨率，不增加1920×720预设；已保存该尺寸的设置转为自定义，保留宽高。
- 音频日志增加接收包数、字节数、解密与格式错误、送入播放管线数量、解码后缓冲区数量及接收静默时长，按周期汇总，避免逐包刷日志。
- 麦克风授权等待与当前会话绑定，停止或重连后忽略旧授权结果；采集或编码失败时停止麦克风管线，防止旧回调影响新会话。

## 使用方法

退出旧版后，按芯片选择安装包，将MacPlay拖入“应用程序”替换旧版。已有设置、配对与本机认证文件保留。

| 安装包 | 适用设备 |
| --- | --- |
| `MacPlay-1.2.2-arm64.dmg` | AppleM系列Mac |
| `MacPlay-1.2.2-x86_64.dmg` | Intel Mac |

- 系统要求：macOS14及以上。
- USB连接：连接iPhone并解锁，在MacPlay选择有线连接后启动接收。
- 无线连接：两端加入允许互访的Wi-Fi，完成蓝牙配对，填写SSID、密码和信道后启动接收。
- 调整窗口：在“显示→视频分辨率”选择是否严格按物理像素显示，点击“应用并重新连接”。
- CarPlay界面大小：在CarPlay的“设置→显示屏→智能缩放显示”调整；MacPlay窗口适配不会替你切换这一设置。
- 问题反馈：在“关于→日志”导出当前日志，附上连接方式和具体表现。
