# MacPlay1.2.0更新说明

本次更新加入多语言、USB自动启动与菜单栏后台运行，并完善CarPlay窗口关闭和断开后的返回行为。

## 新增功能

- 多语言：支持跟随Mac系统、简体中文、繁體中文和English。在“连接→应用→语言”中选择，更改后立即更新MacPlay界面；CarPlay内部语言仍跟随iPhone。
- USB自动启动：在“连接→应用”开启“USB接入时自动启动CarPlay”，MacPlay运行期间接入目标iPhone即可启动有线接收。首次连接仍需解锁iPhone并确认信任，手动停止后不会因为数据线仍插着而反复启动。
- 后台运行：开启“允许后台运行”后，关闭主窗口会继续接收。菜单栏显示简约图标，可打开主窗口、显示CarPlay、启动/停止接收或退出。该选项不设置开机启动。

## 窗口与连接优化

- 主动停止或已建立的会话被动断开后，关闭CarPlay窗口，返回连接主页并恢复“启动接收”。
- 点击CarPlay窗口的红色关闭按钮，先确认是否断开连接；取消后继续保持连接。
- 主窗口和CarPlay画面共用MacPlay的Dock入口，Dock菜单可分别打开两个窗口，接收子进程不新增node图标。
- 点击CarPlay中的MacPlay入口，打开MacPlay主窗口。
- 保留高帧率启动回退：120fps请求失败后依次尝试90fps、60fps，正常断开不作为降档条件。

## 密码读取提示

“读取已保存密码”的结果独立显示在按钮下方。读取失败时显示实际系统状态码及可用的系统说明，避免被自动刷新网络名称的提示覆盖。仍可手动填写Wi-Fi共享密码。

## 安装包

要求macOS14及以上，请按Mac芯片选择安装包：

| 安装包 | 适用设备 |
| --- | --- |
| `MacPlay-1.2.0-arm64.dmg` | AppleM系列Mac |
| `MacPlay-1.2.0-x86_64.dmg` | Intel Mac |

更新前退出旧版MacPlay，再将DMG中的应用替换到“应用程序”。已有设置和本机认证文件继续使用。USB自动启动和后台运行默认关闭，可按需要开启。

项目与使用方法：[Roylyl/MacPlay](https://github.com/Roylyl/MacPlay)

## 界面整理

- 移除侧栏“诊断”页，主窗口保留连接、显示、音频和关于四页。
- 日志查看、导出和认证文件管理统一放入“关于”；最近日志与认证文件默认折叠。
- 移除自动更新和日志操作的常驻说明，保留检查结果与实际错误。
- “关于”页不再显示接收操作栏，避免与页面用途无关的按钮。
- 避免重复的发行说明入口；没有本机安装包时，更新弹窗提供发行说明入口。
- 关闭自动检查后不再弹出正在进行的自动请求所产生的更新提醒。

## 关于、更新与日志

在侧栏最后的“关于”页查看版本号、构建号和运行架构。点击“检查更新”读取GitHub正式发行版，按版本号比较，并为当前Mac选择M系列或Intel安装包；通过Rosetta运行时仍优先选择M系列版。没有对应安装包时可打开发行说明。

“自动检查更新”默认开启，应用启动或回到前台时每天检查一次，发现新版在主窗口提示；同一版本确认后不重复提醒。检查失败会显示错误，手动检查不受每日频率限制。点击“下载更新”后通过浏览器下载，退出旧版再替换应用，不自动安装。

在“关于→日志”点击“导出日志”，选择位置保存TXT。导出当前连接日志，过滤网络密码及常见设备标识，不包含设置文件或认证文件。发送给他人前仍可自行查看导出内容。


## 窗口入口修正（构建33）

- 点击菜单栏或Dock菜单中的“显示MacPlay”只唤起主窗口。
- 点击“显示CarPlay”只唤起CarPlay窗口，不额外打开主窗口。
- 普通点击Dock图标打开MacPlay主窗口。
