## 使用前提与发布边界

公开DMG没有配件认证材料。用户需自行导入有权使用且匹配的证书与私钥，才能建立CarPlay连接。项目维护者确认没有可随应用公开分发的认证材料，因此不将本机实验身份加入安装包，也不提供提取或下载它们的操作。

当前采用本地签名而非Developer ID公证，用户可能需要在系统隐私与安全性页面确认打开。

发行DMG应同时提供对应的构建20源码与构建资料。发布其他构建时同步版本说明与源码，不以旧标签代替新二进制对应源码。第三方许可已随包附带，但本次没有逐项完成第三方源码提供义务与法律授权审查。
