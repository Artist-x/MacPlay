# MacPlay1.2.1

本次更新完善无线断线检测与自动重连，改进连接状态、网络配置、媒体同步和后台更新检查。

## 更新内容

- 新增“无线连接被动断开时自动重连”开关，位于“连接→共用Wi-Fi”，默认关闭。仅回连已成功连接后被动断开的iPhone，使用上次应用的连接配置。
- 重连依次等待5、10、20、30、60秒，后续保持60秒；主动停止、确认断开、退出或关闭开关取消后续尝试。USB自动启动保持独立。
- 增加TCP保活与心跳存活检测。确认iPhone提供心跳后，控制、媒体及心跳活动持续约15秒中断时结束会话并关闭冻结画面；未确认心跳时不因静态画面或暂停音乐直接断线。
- 视频启动后避免旧握手消息覆盖连接状态。120/90fps继续按原有规则降档，最终60fps尝试等待视频超过45秒会结束，启动全过程也有等待上限。
- 读取不同Wi-Fi时清除旧密码；同一网络读取密码失败保留已有输入。启动时检查当前可读取的Wi-Fi名称与连接配置是否一致。
- 日志加入连接尝试编号、阶段耗时、接口、地址族、信道、分辨率、帧率、首批媒体数据及断开原因。保留最近1000行并合并写盘，继续过滤密码和常见设备标识，入口仍在“关于→日志”。
- 每次启动检查更新，持续运行时每两小时静默检查；后台检查只更新关于页结果，不弹出对话框。关闭自动检查后停止定时请求。
- 合并高频歌词与播放进度的系统媒体更新，保留封面独立更新、曲目切换重置及进度跳转回传。
- 包含CarPlay画面窗口前置修正，支持恢复最小化窗口；视频配置更新不反复抢焦点，不永久置顶。

## 安装与升级

要求macOS14及以上，请按芯片选择：

| 安装包 | 适用设备 |
| --- | --- |
| `MacPlay-1.2.1-arm64.dmg` | AppleM系列Mac |
| `MacPlay-1.2.1-x86_64.dmg` | Intel Mac |

退出旧版后，将DMG中的MacPlay替换到“应用程序”。保留已有设置、配对记录和本机认证文件。无线自动重连默认关闭，按需要开启。
